# 北京联合大学校园 Skill（BUU Campus Skill）

面向 **北京联合大学 2026 级新生（兼顾全体在校生）** 的校园问答与办事指引 Agent Skill。把分散在学校官网、官方文件、通知里的信息整理成结构化知识库，导入支持 SKILL.md 的 AI 助手后，直接用自然语言提问即可获得带来源、可核实的回答。

兼容 **腾讯 Marvis（马维斯）** 以及任何支持标准 `SKILL.md` 技能包的 Agent 平台（Claude Code、Cursor、Codex 等）。

## 能回答什么

- 新生预报到、报到时间地点、缴费、网上选床、材料清单、户口/党团关系、绿色通道、军训
- 7 个校区与 14 个学院的对应关系、地铁路线、各校区电话
- 宿舍、食堂、校园卡、校园网/WebVPN、图书馆、校医院、快递
- 选课、绩点、补考重修、学业警示、**转专业**、辅修/双学位/微专业、**保研推免**、四六级
- 国家/校级奖学金、助学金、助学贷款、勤工助学、综测、学生事务窗口
- 170+ 学生社团、艺术团、学生组织、第二课堂
- 校内信息系统入口、账号密码规则、各部门官方电话
- 40+ 条新生高频 FAQ 与开学防坑提醒

## 安装方式

### Marvis（马维斯）
1. 下载本仓库（Code → Download ZIP）或在 Release 下载打包好的技能 zip；
2. Marvis 客户端 → 技能/技能广场 → **导入自定义 Skill** → 选择该压缩包（保持包内 `SKILL.md` 在 `beijing-union-university/` 目录下）；
3. 导入后直接对话提问即可自动触发，例如「管理学院新生去哪报到」「联大转专业什么规则」。

### 通用 Agent（Claude Code / Cursor / Codex 等）
把 `beijing-union-university` 文件夹放入对应的 skills 目录（如 `~/.claude/skills/`），Agent 会按 frontmatter 中的 description 自动匹配触发。
