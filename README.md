# 北京联合大学校园 Skill（BUU Campus Skill）

面向 **北京联合大学 2026 级新生（兼顾全体在校生）** 的校园问答与办事指引 Agent Skill。把分散在学校官网、官方文件、通知里的信息整理成结构化知识库，导入支持 `SKILL.md` 的 AI 助手后，直接用自然语言提问即可获得带来源、可核实的回答。

适用于**豆包、千问（Qwen）、Marvis（马维斯）、Claude Code、Cursor、Codex、WPS 灵犀 Claw** 等任何支持标准 `SKILL.md` 技能包的 AI 助手/Agent 平台。

## 能回答什么

- 新生预报到、报到时间地点、缴费、网上选床、材料清单、户口/党团关系、绿色通道、军训
- 7 个校区与 14 个学院的对应关系、地铁路线、各校区电话
- 宿舍、食堂、校园卡、校园网/WebVPN、图书馆、校医院、快递
- 选课、绩点、补考重修、学业警示、**转专业**、辅修/双学位/微专业、**保研推免**、四六级
- 国家/校级奖学金、助学金、助学贷款、勤工助学、综测、学生事务窗口
- 170+ 学生社团、艺术团、学生组织、第二课堂
- 校内信息系统入口、账号密码规则、各部门官方电话
- 40+ 条新生高频 FAQ 与开学防坑提醒

## 如何使用

### 第一步：获取技能文件

两种方式任选其一：

1. **下载 zip**：GitHub 仓库主页 → 绿色 `Code` 按钮 → `Download ZIP`，解压后得到 `beijing-union-university/` 文件夹；
2. **git clone**：`git clone https://github.com/YTZ-create/beijing-union-university-skill.git`

文件夹内必须包含 `SKILL.md` 和 `references/` 目录，这是技能的核心。

### 第二步：按你的平台导入

#### 🟢 豆包（Doubao）

- **桌面端 Agent 模式**：把 `beijing-union-university/` 整个文件夹放入用户技能目录（通常为工作区下的 `.user_skills/`），或在技能管理中选择「导入技能」并选中该文件夹/zip；刷新或重启后生效。
- **生效后直接对话**即可，例如问「管理学院新生去哪报到」「联大转专业什么规则」「北四环校区怎么坐地铁」，豆包会自动调用本技能。
- 不同版本（网页版 / 手机 App / 桌面 Agent）的技能入口名称可能略有差异，以当前版本界面为准；找不到入口时，把 `SKILL.md` 内容和 `references/` 文件作为自定义指令/知识库粘贴给豆包也能获得同样效果。

#### 🟢 千问（Qwen / 通义千问）

- **Qwen Code 等支持自定义技能的 Agent**：将 `beijing-union-university/` 文件夹放入其技能（skills）目录，或通过导入功能加载该 `SKILL.md` 技能包，重启会话后生效。
- **通义千问 App / 网页版（自定义智能体方式）**：
  1. 创建一个自定义智能体（Bot）；
  2. 把 `references/` 目录下的 9 个 `.md` 文件作为**知识库**上传；
  3. 把本仓库 `SKILL.md` 中的「回答工作流」「回答铁律」「信源优先级」等规则粘贴到智能体的**系统设定/人设提示词**中；
  4. 保存后即可在对话中提问。
- 千问各产品对标准 `SKILL.md` 的原生支持程度不同，以上为推荐用法，具体以产品实际功能为准。

#### 🟢 Marvis（马维斯）

1. 打开 Marvis 客户端 → 进入「技能 / 技能广场」；
2. 选择「导入自定义 Skill」→ 选中下载的技能 zip（或解压后的 `beijing-union-university/` 文件夹）；
3. 导入完成后在对话中直接提问即可自动调用，例如「联大宿舍咋样」「助学金怎么申请」。
4. 如本技能后续上架 Marvis 技能广场，也可直接在技能广场搜索「北京联合大学」一键装载。

#### 🟢 其他 Agent（Claude Code / Cursor / Codex / WPS 灵犀 Claw 等）

把 `beijing-union-university/` 文件夹放入对应 Agent 的技能目录即可，例如：

- Claude Code：`~/.claude/skills/`
- Cursor / Codex / WPS 灵犀 Claw：各自的自定义技能/指令目录（以产品文档为准）

Agent 会读取 `SKILL.md` 顶部 frontmatter 中的 `description`，在用户问到联大相关问题时自动触发。

### 第三步：开始提问（示例）

| 你可以这样问 | 技能会怎么答 |
|---|---|
| 「我是管理学院新生，去哪报到？要带啥？」 | 给出北四环校区报到点、9 月 6 日报到时间、必带材料清单、选床与缴费入口 |
| 「联大可以转专业吗？什么时候申请？」 | 引用《学生转专业实施办法（修订）》说明一、二年级第二学期申请、双向选择、限制情形与当年计划查询方式 |
| 「宿舍晚上断网吗？有空调吗？」 | 说明 6–8 人间、空调暖气、公寓上网 6:00–23:00、可办运营商宽带 |
| 「国家奖学金多少钱？怎么评？」 | 说明 10000 元/年（2024 年起标准）、面向二年级以上、看成绩+综测，并引导到学院/学生处通知 |
| 「北四环校区怎么坐地铁？」 | 给出 5 号线惠新西街北口 B 口 + 步行路线，并提示校内不提供停车 |
