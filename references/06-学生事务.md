# 06 学生事务（奖助勤贷、综测与日常办事）

> 来源：学生处（ldxsc.buu.edu.cn）公开文件、《学生手册》、国家及北京市 2024–2025 年奖助政策调整通知、招生问答。奖助金额近年有国家标准上调，回答时务必标注口径年份并提示以当年评定文件为准。

## 一、资助体系总览

学校建立「**奖、贷、助、勤、补、减（免）+ 绿色通道**」全覆盖资助体系：奖学金、国家助学贷款、助学金、勤工助学、临时/困难补助、学费减免、新生入学绿色通道。咨询：学生资助管理中心 **010-64900260**。

## 二、奖学金

### 1. 国家级（面向二年级及以上在校生，金额为国家标准）
| 项目 | 标准（注意年份口径） | 要点 |
|---|---|---|
| 国家奖学金 | **10000 元/年**（2024 年秋季起由 8000 上调至 10000） | 成绩与综测特别优异，名额由上级下达 |
| 国家励志奖学金 | **5000 元/年** | 品学兼优的家庭经济困难学生 |
| 新生入学奖学金 | 曾执行 2000 元/人（面向京外生源前列新生，**以当年招生政策为准**） | 不含艺术类、单招师范等类别 |

### 2. 校级（按《学生手册》评比，以最新版为准）
- 设**校长特别奖学金**及特等奖学金（曾执行 3000 元/人·学年）、一、二、三等奖学金等，依据**德智体美劳综合测评（综测）**排名评定，具体金额与比例以当年学生手册为准【精确分档待核实，勿编造】。
### 3. 社会奖助学金
- 企业/校友设立的社会奖（助）学金，按当年捐赠协议与评选通知申请。

## 三、助学金与困难认定

- **国家助学金（北京市属高校口径）**：分档发放，曾执行一等 320 元/月、二等 160 元/月、按 10 个月发放的旧标准；**2024–2025 年国家本专科助学金标准已整体上调并优化分档，当前金额以北京市/学校当年文件为准**（回答时不要沿用旧数字下结论）。
- **家庭经济困难学生认定**：新生报到时交《北京联合大学学生及家庭情况调查表》（原件+复印件 2 份），入学后在统一门户提交认定申请；建档立卡、低保、特困供养、孤儿、优抚对象、残疾学生及子女、烈士子女、低收入家庭等持相应证件认定。
- **临时困难补助**：在校期间遭遇突发困难可向学院申请。
- **生活物价补贴（副食补助）**：全体正式录取本专科生享有，**师范生 200 元/月、非师范生 60 元/月**，按月打入本人北京银行卡，2 月、8 月不发。

## 四、国家助学贷款

- **生源地信用助学贷款**（推荐）：开学前到生源地县（区）学生资助管理部门办理，报到当天把《受理证明》交学院。
- **校园地助学贷款**：入学后按学校通知申请。
- 贷款额度、贴息政策按国家当年标准执行（本专科生额度近年已提高，以当年国家开发银行/资助中心口径为准）。

## 五、勤工助学

- 校内设图书馆、行政助理、实验室助理等勤工助学岗位，按《学生勤工助学管理办法（修订）》管理，酬金按月发至北京银行卡；岗位招聘每学年初由学生处/各单位发布。
- 校外兼职注意防骗，不参与刷单、代写、收费中介类「兼职」。

## 六、新生绿色通道

- 暂时凑不齐学费的新生**先入学、后办手续**：报到当天在学院「绿色通道」提交困难证明原件备查，入学后再办贷款/缴费/困难认定；咨询 010-64900260。
- 公费师范生免学费并有生活补贴（详见 04/02），不属于困难资助范畴但同样走注册流程。

## 七、综合测评（综测）

- 每学年对学生**德、智、体、美、劳**综合量化评价，是评奖评优、推优入党、推免保研、奖学金的核心依据。
- 由班级/学院按学校综测办法核算，学业成绩为基础，叠加科研竞赛、学生工作、志愿服务、文体活动等加分；细则与加分目录以学院当年公布为准。

## 八、学生日常办事清单

| 事项 | 一般办理路径 |
|---|---|
| 学生证补办、火车票学生优惠卡充磁 | 辅导员开证明/学院登记 → 学生事务服务中心（或按学院教务/学工办安排） |
| 在读/在校证明、成绩单 | 统一门户自助打印或学生事务服务中心盖章 |
| 请假 | 短期向班主任/辅导员请假，较长假期走学院审批与教务备案 |
| 休学/复学/退学/转学 | 本人申请 → 学院审核 → 教务处/学生处审批（见 04） |
| 奖助学金/贷款/困难认定 | 班级通知 → 统一门户申请 → 学院评审公示 → 学生处 |
| 党团事务、推优入党 | 学院团委/党支部，团关系问题见 02 |
| 征兵入伍、基层就业学费补偿 | 辅导员 + 学校武装部/学生资助中心，按当年征兵通知 |
| 违纪申诉、学籍学位异议 | 先向学院学工/教务反映，按学生手册规定程序申诉 |
